# Gemma 4 AI Hackathon Project

A privacy-first multimodal AI assistant powered by Google's Gemma 4 models.

This project explores running Gemma 4 locally for AI applications involving
text, images, and audio, with a focus on privacy, local inference, and
developer-friendly usage.

## 🚀 Features

- 🤖 Powered by Gemma 4
- 📝 Text understanding and generation
- 🖼️ Multimodal image understanding
- 🎵 Audio input support
- 🔒 Privacy-focused local inference
- ⚡ ONNX Runtime-based execution
- 🧩 TypeScript / Node.js based implementation
- 🛠️ Support for agent and tool-calling workflows

## 💡 Why Gemma 4?

Gemma 4 provides powerful multimodal AI capabilities while making it possible
to explore AI inference locally.

This project demonstrates how Gemma 4 can be integrated into a developer
workflow without depending entirely on external AI APIs.

## 🏗️ Technology Stack

- Google Gemma 4
- TypeScript
- Node.js
- ONNX Runtime
- Hugging Face Transformers
- pnpm

## 🔐 Privacy

The project is designed around local inference. After the required model files
are downloaded, inference can run on-device without sending prompts to a
third-party AI API.

## 🎯 Hackathon Goal

The goal of this project is to explore practical applications of Gemma 4 and
demonstrate how a local multimodal AI system can be integrated into modern
applications.
